# Notebooks

Interactive versions of the repo's verification demos.

| file | covers |
|---|---|
| `01_transformer_walkthrough.ipynb` | scaled dot-product attention → seq2seq attention heatmaps → GPT sampling → KV-cache equivalence → RoPE Toeplitz property → length extrapolation → GQA cache math |

## Run

```bash
source venv/bin/activate
pip install -r ../requirements.txt   # kernelspec for the venv: python3 -m ipykernel install --user
jupyter notebook notebooks/
```

Start Jupyter from the repo root as above — the kernel's working directory is
`notebooks/`, and cell 1 derives the repo root and `checkpoints/` from it.

Cells are executed top to bottom and print the same numbers as the CLI
scripts (`scripts/verify.py`, `src/transformer/attention.py`, ...).
Checkpoints in `checkpoints/` must exist (they do by default).

## Regenerate

The notebook is generated by `../build_notebook.py` (keeps the JSON
canonical; `--execute` also runs every cell with nbclient):

```bash
source venv/bin/activate && python3 build_notebook.py --execute
```

Note: `scripts/gpt.py`'s checkpoints pickle the tokenizer as
`__main__.CharTokenizer`, so any loader (scripts *and* notebooks) must import
`CharTokenizer` before `torch.load` — both `scripts/verify.py` and the
notebook do.
