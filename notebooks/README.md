# Notebooks

Interactive versions of the repo's verification demos.

| file | covers |
|---|---|
| `01_transformer_walkthrough.ipynb` | scaled dot-product attention → seq2seq attention heatmaps → GPT sampling → KV-cache equivalence → RoPE Toeplitz property → length extrapolation → GQA cache math |

## Run

```bash
source venv/bin/activate
pip install jupyter ipykernel nbformat   # kernelspec for the venv: python3 -m ipykernel install --user
jupyter notebook notebooks/
```

Cells are executed top to bottom and print the same numbers as the CLI
scripts (`rope_gen.py`, `deepdive.py`, ...). Checkpoints and `model.pt` must
exist in the repo root (they do by default).

## Regenerate

The notebook is generated by `../build_notebook.py` (keeps the JSON canonical):

```bash
source venv/bin/activate && python3 build_notebook.py
```

Note: `gpt.py`'s checkpoints pickle the tokenizer as
`__main__.CharTokenizer`, so any loader (scripts *and* notebooks) must import
`CharTokenizer` before `torch.load` — both `rope_gen.py` and the notebook do.
